# Інформаційна система університету

Навчальний проєкт на HTML, CSS і чистому JavaScript для демонстрації таблиць сутностей університету: студентів, викладачів і дисциплін.

## Реалізовано

- Перемикання між трьома таблицями без перезавантаження сторінки.
- Видалення рядків кнопкою `×` із підтвердженням дії.
- Перевірка зв’язків: викладача не можна видалити, якщо він зазначений у дисциплінах. Відображається повідомлення з переліком пов’язаних дисциплін.
- Редагування значень кліком по комірці (крім ID): введіть значення та натисніть `Enter` або клацніть поза полем. `Escape` скасовує редагування.
- Перевірка числових значень і перевірка наявності викладача під час редагування дисципліни.
- Якщо змінити ПІБ викладача, його ім’я автоматично оновиться у пов’язаних дисциплінах.
- Кількість записів оновлюється після змін.

## Запуск

1. Завантажте або клонуйте репозиторій.
2. Відкрийте `index.html` у сучасному браузері.
3. Дані демонстраційні й зберігаються в масивах JavaScript лише до перезавантаження сторінки. Сервер або база даних не потрібні.

## Публікація на GitHub

1. Створіть новий репозиторій на GitHub і встановіть видимість **Public**.
2. Завантажте `index.html`, `style.css`, `script.js` і `README.md`.
3. У звіті до лабораторної роботи додайте посилання на публічний репозиторій.

Проєкт не використовує сторонні бібліотеки чи фреймворки.
